# 🛡️ Python Password Strength Analyzer (GUI)

A simple, interactive desktop application built with **Python** and **Tkinter** that evaluates how secure your passwords are. It provides real-time feedback, estimated crack times, and specific suggestions for improvement.

## ✨ Features
*   **Visual Interface**: Easy-to-use GUI (Graphical User Interface) powered by Tkinter.
*   **Security Scoring**: Checks for length, numbers, special characters, and casing.
*   **Crack Time Estimation**: Gives you a rough idea of how fast a hacker could guess your password.
*   **Smart Suggestions**: Tells you exactly what's missing (e.g., "Add uppercase letters" or "Include special characters").
*   **Privacy Focused**: Runs entirely on your local machine; your passwords are never sent to the internet.

## 🚀 How to Run
1.  **Ensure you have Python installed**:
    Check by typing `python --version` in your terminal.
2.  **Download the script**:
    Save the code as `password_analyzer.py`.
3.  **Run the application**:
    ```bash
    python password_analyzer.py
    ```

## 🛠️ Built With
*   [Python](https://www.python.org) - The programming language used.
*   [Tkinter](https://docs.python.org) - Python's built-in library for creating desktop windows.

## 📸 How it Works
The app calculates a score based on 6 security rules:
- Length (8+ and 12+ characters)
- Presence of Uppercase letters
- Presence of Lowercase letters
- Presence of Numbers
- Presence of Special characters (!@#$%^&*)
